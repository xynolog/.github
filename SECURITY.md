# Security Policy

## Supported Versions

Security fixes are provided for the latest release of each repository.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security problems.

Report vulnerabilities privately through GitHub Security Advisories:

- Go to the repository's **Security** tab and press **Report a
  vulnerability**.

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce
- Affected version(s)
- Suggested fixes, if any

Maintainers will acknowledge your report and respond as soon as possible.
Please allow reasonable time for a fix before any public disclosure.
